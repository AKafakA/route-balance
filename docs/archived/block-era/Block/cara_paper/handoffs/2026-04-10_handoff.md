## Key Findings

1. **RoBERTa fused wins** for length/ref_score/deepeval. LoRA-encoder comparable but slightly worse.
2. **KNN dominates similarity** (94.2% BestModelAcc) — trivial because 72B ≈ 1.0.
3. **Qwen LLM worst** on regression targets but best BestModelAcc on judge (60.7%).
4. **Multi-target bucket MAE fixed** (~105 after tie-handling correction, was ~205 due to bug).
5. **XGBoost latency** is excellent with oracle output length (1-6% MAPE) but this uses actual tokens — at deployment, Cara's length predictor provides the estimate.
6. **LSTM v2 = blind baseline** — per-request queue features don't help because data has low contention (num_waiting ≈ 0). Need overloaded QPS data from CloudLab.
7. **SLO filters work** — CaraCDF provides good precision/recall balance. All filters high F1 at moderate SLOs; differentiation shows at tight SLOs (5s E2E).
8. **Latency data confirmed clean** (sweep 2, no concurrency cap). num_waiting ≈ 0 is normal vLLM continuous batching.

## SLO Filtering Baselines + Ablation Study (Task #17)

### Design (for fresh context session)
Two-layer online experiment on CloudLab:

**Layer 1: External Baselines** (round-robin scheduling, isolate filtering)
| Filter | Accept Condition | Paper |
|--------|-----------------|-------|
| SLOs-Serve | `pred_ttft ≤ SLO AND pred_tpot ≤ SLO` (binary) | arXiv 2504.08784 |
| PolyServe | `pred_ttft + output × pred_tpot ≤ deadline` (cumulative) | arXiv 2507.17769 |
| QLM | `pred_ttft + z·σ ≤ SLO` (Normal confidence) | arXiv 2407.00047 |
| Cara-hard | `P(ttft ≤ SLO) ≥ θ` (CDF, hard reject) | Ours |
| Cara-relaxed | Same + tiered relaxation | Ours |

**Layer 2: Cara Internal Sensitivity** (full multi-objective scheduling)
- θ (confidence threshold): 0.5, 0.6, 0.7, 0.8, 0.9
- Relaxation order variations
- Relaxation step size, max rounds

**Layer 3: Main Comparison**
- Best external baseline vs full Cara system

**Papers to read BEFORE implementation:**
- SLOs-Serve §3 admission control
- PolyServe §3 deadline formulation
- QLM §4 CLT confidence bounds

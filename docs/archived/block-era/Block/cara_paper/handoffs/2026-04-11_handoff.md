## Key Lessons (April 9-11)

1. **CSD3 workflow**: ALWAYS smoke test via INTR before sbatch (see memory/feedback_csd3_workflow.md)
2. **RoBERTa max_length**: Must be 512 (position embeddings = 514)
3. **Cross-model metrics**: Handle ties in BestAcc/Top2Acc
4. **Multi-target bucket**: Check `"classification" in problem_type` not `== "classification"`
5. **KNN per_judge_scores**: Must be saved in pickle; rebuild for deepeval/prometheus targets
6. **Never modify existing venvs** — use separate venvs (`.venv_roberta`)
